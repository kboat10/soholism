# Security and scope

## What we test

Only the equipment and virtual machines that make up this lab, owned by the project members. Nothing else.

## What we never do

- Scan, probe or log in to any system we do not own.
- Test a business network without a signed, written scope (what, when, how, who to call if something breaks).
- Commit private keys, passwords, real public IP addresses or personal data to this repository.

## Laws that apply to us

- **UK:** Computer Misuse Act 1990; UK GDPR and the Data Protection Act 2018.
- **Ghana:** Cybersecurity Act 2020 (Act 1038); Data Protection Act 2012 (Act 843).

As a two-country team, we follow whichever rule is stricter.

## Found a problem in this repo?

If you spot a leaked secret or a mistake that could put someone at risk, please open a private security advisory (Security tab → Report a vulnerability) rather than a public issue.
