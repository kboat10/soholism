## Weekly call

- **When:** _day and time, GMT_ (Ghana is UTC+0; the UK is UTC+0 in winter, UTC+1 in summer)
- **Where:** _link_
- **Agenda:** what got done, what's blocked, demo one thing, pick next week's issues

## Working agreement

1. Every change goes through a pull request reviewed by the other person.
2. An issue is done only when its write-up or notes are in the repo.
3. If you're blocked for more than a day, say so in the issue.
4. No secrets in commits. Sanitise configs with `scripts/sanitise-config.sh` first.
